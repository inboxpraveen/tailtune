# Getting help

- **Questions, setup help and ideas:** [GitHub Discussions](https://github.com/inboxpraveen/tailtune/discussions).
  Search first; your question may already have an answer.
- **Bugs:** [open an issue](https://github.com/inboxpraveen/tailtune/issues/new/choose)
  with the output of `tailtune doctor --json`. It makes no network calls and contains
  no secrets.
- **A model that `tailtune estimate` refuses:** use the model-support issue template.
- **Security vulnerabilities:** never in public. See [SECURITY.md](SECURITY.md).

There is no private support by direct message or email. Answers given in public help
the next person with the same problem.
